Erreur "Connexion non privée" ?

Le Gateway IB utilise un certificat SSL auto-signé. C'est normal et sécurisé.

Solution dans Chrome/Edge :

  1. Cliquez sur "Paramètres avancés"
  2. Puis "Continuer vers localhost (dangereux)"
  3. OU tapez directement : thisisunsafe sur la page d'erreur

Solution dans Firefox : Cliquez sur "Avancé" → "Accepter le risque et continuer"
